# NBR Installer downloads

Official Windows downloads and signed in-app updates for NBR Installer.

Download the latest setup from [Releases](https://github.com/eyonasa/nbr-installer-releases/releases/latest).
Existing installations without the updater need a one-time manual upgrade.
Newer releases can then be installed from the app.

This repository contains release artifacts and update metadata, not signing keys or account data.

NBR Installer is based on [iloader by nab138](https://github.com/nab138/iloader) (MIT).
